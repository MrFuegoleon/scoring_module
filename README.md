# Mini App - Test Modules

Structure minimaliste:

- `frontend/` - React Vite
- `backend/` - Express
- `python/` - Scripts Python

## Lancer

```bash
# Terminal 1 - Python
cd python
pip install -r requirements.txt
python app.py

# Terminal 2 - Backend
cd backend
npm install
npm start

# Terminal 3 - Frontend
cd frontend
npm install
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:3001
Python: http://localhost:5000
